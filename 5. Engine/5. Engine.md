# The important concept

Normally:

```bash
docker run nginx
```

means:

```text
Your machine
    ↓
Docker CLI
    ↓
Docker Engine on your machine
    ↓
nginx container
```

With `-H`:

```bash
docker -H 10.123.2.1:2376 --tlsverify run nginx
```

it becomes:

```text
Your machine
    ↓
Docker CLI
    ↓
Network connection
    ↓
Docker Engine at 10.123.2.1:2376
    ↓
nginx container
```

So **the container runs on the remote Docker host**, not on your local machine.

### What is `2376`?

`2376` is the commonly used port for a **Docker daemon secured with TLS**.
