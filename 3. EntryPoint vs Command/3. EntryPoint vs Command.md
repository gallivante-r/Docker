The key difference is **what command Docker runs when the container starts**.

### 1. Explicitly give `bash`

```bash
docker run -it ubuntu bash
```

You are telling Docker:

```text
Start Ubuntu container
        ↓
Run `bash`
        ↓
Give me an interactive terminal
```

So `bash` is the **command** being executed inside the container.

---

### 2. Don't give a command

```bash
docker run -it ubuntu
```

Now Docker has to use the **default command configured by the Ubuntu image**.

For the official Ubuntu image, its default command is effectively:

```bash
bash
```

So in this particular case:

```bash
docker run -it ubuntu
```

and

```bash
docker run -it ubuntu bash
```

will normally give you essentially the **same result**: an interactive Bash shell.

---

### Why does this work?

An image can define:

```dockerfile
CMD ["bash"]
```

The Ubuntu image has a default command that starts Bash.

So conceptually:

```text
docker run -it ubuntu
                    ↓
              image's CMD
                    ↓
                  bash
```

Whereas:

```text
docker run -it ubuntu bash
                    ↓
             your command
                    ↓
                  bash
```

### The important general rule

If you run:

```bash
docker run IMAGE
```

→ Docker uses the image's **default CMD/ENTRYPOINT**.

If you run:

```bash
docker run IMAGE COMMAND
```

→ you provide a command, which can **replace the image's default CMD** (subject to ENTRYPOINT).

So:

```bash
docker run -it ubuntu bash
```

is more explicit.

```bash
docker run -it ubuntu
```

means:

> "Run Ubuntu using whatever default command this image defines."

**For Ubuntu specifically, both effectively start Bash.**

---

# Command vs Entrypoint

* CMD ["bash"] : bash is a shell that listen to input from terminal , if it cN not find a terminal, it exits.

```bash
# sleep 5 ovveride the bash command
docker run ubuntu sleep 5

# fixed executable and args
CMD ["sleep", "5"]

# fixed executable but dynamic args
Entrypoint["sleep"]
docker run ubuntu 10

# dynamic executable and args
Entrypoint["sleep"]
CMD ["5"]
```
